# Information Theory Labs

Лабораторные работы по дисциплине «Основы теории информации».

Бут Иван Антонович, БИВТ-24-СП-3. Преподаватель Александр Кривяков.

## Работы

| Папка | Работа | Состояние |
|---|---|---|
| [lab-01](lab-01/) | Локальный Lakehouse, ELT и бенчмарк форматов и кодеков. Вариант 3, TPC-H Q18, SF5 | Выполнена и проверена |

Следующие работы будут добавлены отдельными папками `lab-02` и `lab-03`, без смешивания скриптов и результатов.

## Практическая работа 1

- [Короткий отчёт](lab-01/report.md), [Word с титульником](lab-01/report.docx).
- [Табличный отчёт](lab-01/report-tables.md).
- [Инструкция запуска и методология](lab-01/README.md).
- [Исходный Q18](lab-01/sql/00_source_q18.sql).
- [Результаты бенчмарка](lab-01/results/q18-format-benchmark.csv), [статус тестов](lab-01/results/status.json), [проверка Spark](lab-01/results/spark-integration.json).

Получены слои Bronze/Silver/Gold, актуальная витрина из 100 заказов. Все 18 прогонов Q18 на шести сочетаниях формата и кодека совпали с исходным результатом. Изменение схемы, time travel и rollback проверены. Spark читает тот же Iceberg Lakehouse; GPU не использовался.

Запускайте скрипты из папки `lab-01`, а не из корня репозитория. Данные Docker volumes и образы в Git не входят: на другом компьютере данные нужно воспроизвести по инструкции. Сохранённые результаты старого запуска не перезаписывайте.
